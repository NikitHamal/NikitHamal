# Writer R notes (instructions with strict output formats, then money-focused math-word)

Conventions: the reply is ONLY the requested shape. number only -> bare number (`340`; single digit `9.`); one word
-> word + period (`rara.`); yes/no -> `ho.` / `haina.` / `chha.` / `chhaina.` / `Yes.` / `No.`; with a unit -> `5.5 km`,
`1300 rupiya`; capitals -> `KATHMANDU` (no period); first letter -> `J.`; lists on one line (`a, b, c` or `1. a 2. b`);
answer + reason -> `haina, kinabhane ...` in one line. Rounding T: names the deciding digit(s) (`antim dui ank 67, 50
bhanda badhi: 1900`; 5 and 50 round up). A few 2-turn items: the slip (a sentence instead of the format) is a C: line,
the user repeats the format, N gives exactly the format.
