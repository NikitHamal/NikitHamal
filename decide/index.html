Nik-Decide

A 5.4M-parameter decision model, built from scratch. It doesn't write text: it reads everything at once and picks an option in one pass, with a confidence for each. Runs fully in your browser. Talk to Nik →

What it was trained on (all from Nik's own audited generators, held-out accuracy): reading yes/no 99.7%, "not mentioned" 100%, picking the answer from a passage 92.9%, checking arithmetic answers 82.8%, and telling what kind of message something is (chat / math / reading / about Nik or Nikit / language / writing) 100%. It is small and narrow: outside these task types its choices are guesses. For yes/no, write the options like ho, pokhara / haina, pokhara haina / thaha chhaina (the format it learned).
