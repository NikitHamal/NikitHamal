What it is for

Nik (the chat model) writes; Nik-Decide checks and routes. It can tell whether a passage supports a claim, notice when something was never mentioned, pick an answer from a text, verify an arithmetic result, spot a working line that uses a number the question never gave, and tell chat from math, reading, persona, language or writing requests.

Limits

The percentages above are held-out rows from Nik's own audited generators; the 11/20 is Local-A's hand-written reading test with vocabulary it never saw (both answers of a pair, both option orders, must be right). On open-world text expect the lower number. Outside these task types its choices are guesses. For yes/no, write the options the way it learned them: ho, pokhara / haina, pokhara haina / thaha chhaina.
