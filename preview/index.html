drawn in code

Me, from baby to now, drawn line by line.

Every line here is an SVG path that code wrote. The program measures my face (the shape of the eyes, brows, nose and lips, the jawline, the hairline) and then inks it: contours, strands of hair that follow the way it grows, stubble, flat colour, and shading taken from the real light on my face. Watch it draw. The eyes follow you.

04 · how

How it's drawn

  1. Code finds 478 points on the face (eye corners, lid curves, iris, brows, nostrils, lips, jaw) and splits the picture into hair, skin, clothes and the rest.
  2. Each feature is redrawn as smooth Bézier ink lines, with heavier lids, lighter creases and tapered brow hairs.
  3. Hair is drawn as hundreds of strands that follow how it flows, spaced so they never clump.
  4. The colour is flat, shaded in soft bands that follow how the light actually falls on the face.
  5. Tilted heads are levelled first, so every portrait faces straight on. The result is one SVG made only of paths.
