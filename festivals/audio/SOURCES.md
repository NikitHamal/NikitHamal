# Audio sources — Dashain / Tihar reel

Compiled 2026-10-20. Every file here is licensed for commercial use with **no attribution required** (CC0 / public domain, Mixkit free licences). No CC-BY, CC-BY-SA, YouTube rips, or files with unclear terms.

## Folder layout

- `music/`: original music downloads (MP3/OGG, full length).
- `sfx/`: original compressed SFX downloads (MP3). I deleted Mixkit SFX originals that came as WAV after converting them, to save space. Their resampled copies are in `wav/` and the source URL is listed below.
- `wav/`: **48 kHz / 16-bit / stereo PCM WAV** of every file (made with ffmpeg; mono sources were duplicated to 2 channels). To stay near the size budget, some long files are **trimmed copies with a 1.5 s fade-out**: the music beds that would run past 80 s are cut to the first 80 s, ambiences / long SFX to 12 s, the big ghanta to 15 s, and the bansuri to a 30 s excerpt (0:60–1:30). The full-length originals are in `music/` / `sfx/`, or at the URL.
- Every original and every WAV was checked with ffprobe and decoded end-to-end with `ffmpeg -f null` (all pass. `amb_patan_durbar…mp3` prints one harmless "invalid backstep" mp3 warning).

## Blocked / not used

- **Pixabay (music + sound effects): blocked.** `pixabay.com` returns Cloudflare 403 / "Just a moment…" challenges to curl (impersonating Chrome's TLS fingerprint did not help either). The site's search data loads only through a JS bootstrap call. WebFetch could read track listings but never exposes the `cdn.pixabay.com/download/audio/...` file URLs. The CDN itself serves files (a known file URL returns 200), but the hashed filenames can't be discovered without page HTML or the API, and I had no API key. Promising Pixabay tracks you could download by hand in a browser (Pixabay Content License): "Free Soul Indian Bansuri Music for Festivities and Travel Vlogs" (kalsstockmedia, 3:47; AI-generated), "Cinematic Sitar Alap × Bansuri Flute" (Pixel_Perfect_Productions, 6:34; AI-generated and **Content ID registered**, so it may trigger YouTube claims), "Indian Classical Flute & Tabla" (bineleyas), "Indian - Epic Indian" (HitsLab), "Fast Indian Music Fusion with Tabla Flute" (kalsstockmedia).
- **FreePD**: the site is offline ("The Music Has Moved On… we have officially taken the service offline").
- **Internet Archive (archive.org / Wayback)**: "Temporarily Offline" during this session.
- **Kenney.nl**: reachable (CC0), but its audio packs (impact, interface, RPG, sci-fi, casino, jingles) are game/UI sounds. Nothing there fit a cinematic festival reel better than what is above, so none were used.
- **Sonniss GDC bundles**: multi-GB archives, far over the 150 MB budget. Not downloaded.
- **Mixkit**: the search pages rate-limit (HTTP 429) after a burst. A few Mixkit SFX (#788, #1143) are offered only as MP3, so those were downloaded as MP3.
- No CC0 recording of a *shankha* in a ritual context was found as a clean one-shot. `sfx_conch_shankha_blow` is a clean generic conch blow, and `amb_patan_durbar_bells_conch_nepal` is a real Patan Durbar (Nepal) ambience with bells and conch.

## React Bits "Sound Lab" (checked, NOT used)

Exported audio may be used in commercial products without a stated attribution requirement, but you may not sell or redistribute the sounds or exports on their own. It is a custom licence, not CC0, Pixabay or Mixkit, so under the strict rule for this project it was **not used**.
