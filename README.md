# Hanomi

A cozy pixel-art open-world village survival game — farm, fish, mine, raise animals, ally or conquer neighbouring clans, survive the Blood Moon.

- **Web original** (repo root): https://nikithamal.github.io/hanomi/ — verbatim copy of the browser game.
- **Native C++ rebuild** (`native/`): single 0.8 MB Windows exe, procedural art & synthesised audio, skeletal-rigged characters.
